# 📘 Mathematical Data Analysis Activities in Excel

Welcome to this Excel-based statistical analysis project. This repository includes 8 structured mathematical activities that help in exploring core concepts of statistics using Excel. Each activity is designed around a specific statistical method or distribution, and is supported by visualizations and interpretation.

---

## 📌 Activities Overview

### 📊 Activity 1: Descriptive Statistics
- **Task**: Generate `n = Roll Number + 20` data points.
- **Goal**: Calculate descriptive statistics like Mean, Median, Mode, Variance, Standard Deviation, etc.

---

### 📈 Activity 2: Linear Regression Analysis
- **Task**: Generate two sets of `n = Roll Number + 20` data.
- **Condition**:
  - *Odd Roll Numbers*: Regress X on Y.
  - *Even Roll Numbers*: Regress Y on X.
- **Goal**: Calculate regression line and visualize it using a graph.

---

### 🎲 Activity 3: Binomial Distribution
- **Task**: Generate `n = 20` data points using Binomial distribution with `p = 0.3`.
- **Goal**: Calculate probability and cumulative distribution function (CDF) for all success values. Plot graphs for both.

---

### 🔔 Activity 4: Poisson Distribution
- **Task**: Generate `n = 2 * Roll Number + 50` data points.
- **λ (mean)**: `round(n)`
- **Goal**: Calculate Poisson probabilities and CDF. Visualize both.

---

### 🔍 Activity 5: Normal Distribution
- **Task**: Generate `n = 2 * Roll Number + 50` data points.
- **Mean**: `√n (rounded)`
- **Standard Deviation**: Roll Number
- **Goal**: Define suitable bin size, calculate probability, and plot normal distribution graph.

---

### 🧠 Activity 6: Central Limit Theorem (CLT) Verification
- **Task**: Generate `n = 1000` data points using Poisson distribution with mean `= Roll Number + 20`.
- **Goal**: Generate 100 random samples, compute their means, and prove that these sample means follow a normal distribution. Plot the graph.

---

### 🧪 Activity 7: t-Test Verification
- **Task**: Perform t-Test using sample data provided during lecture.
- **Goal**: Validate the significance of difference between sample means.

---

### 📱 Activity 8: Chi-Square Test for Independence
- **Task**: Use last and second-last digits of mobile numbers.
- **Goal**: Test if mobile number digit allocation is biased or random using Chi-square test.

---

## 🛠️ Tools Used
- **Microsoft Excel** (Functions, Charts, Pivot Tables)
- **Statistical formulas** for manual calculation & interpretation
